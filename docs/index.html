Rose-chan wears Rosé Pine.

Built on 4chan X, it restyles the whole board — not just the script's own dialogs — in both Rosé Pine variants, with an optional animation layer and a few navigation extras.

What you get

The themes are off until you pick one in the new Theme tab. Three additions do start on — the motion layer, smooth scrolling and the back-to-top button — and they apply whether or not a theme is selected. Untick Animations, Smooth Scrolling and Scroll to Top in the same tab for stock behaviour.

Two variants

Rosé Pine Dawn and Rosé Pine Dark, straight from the upstream palette. One click in the header flips between them.

Follows your system

Optionally track your OS light/dark setting and switch itself when your desktop does.

The whole board

Posts, greentext, quotes, files, code blocks, the catalog and pagination — not only 4chan X's own panels.

Motion, if you want it

New posts fade in, menus and dialogs ease open, thumbnails lift on hover. Three speeds, and it honours prefers-reduced-motion.

Tuning

Six accent colours, three density levels, rounded or square corners, a modern font stack, and optional background blur.

Extras

A back-to-top button, a reading progress bar, and smooth scrolling — each independently switchable.

Catalog and settings

The theme reaches every surface 4chan X draws.

One deviation. Dawn's specified gold #ea9d34 measures 2.05:1 against its cream background — unreadable as text. Post subjects and section headings use a deepened gold (#9a6a16, 4.32:1) instead, while the spec value is kept for borders and fills. That is a large improvement but still short of the 4.5:1 the WCAG AA threshold asks for at this text size.

Install

Rose-chan is built on 4chan X and ships as the same userscript. It installs over an existing copy and keeps your settings.

  1. Install Violentmonkey or Tampermonkey for your browser.
  2. Click Install userscript. Your manager will open an install prompt — confirm it. If that link is blocked where you are, the raw copy on GitHub is the same file and installs the same way.
  3. Open any board, click [Settings] in the header, and go to the Theme tab.
  4. Pick Rosé Pine Dawn or Rosé Pine and it applies immediately.
If you already run 4chan X: this replaces it rather than running alongside it — two copies would conflict, and 4chan X warns when it detects that. It shares the same script name, so your existing settings carry over. To go back, reinstall from 4chan-x.net.
No auto-updates. The published file is the no-update build: its @updateURL and @downloadURL point at noupdate.invalid, so your manager never fetches anything on its own. To move to a newer build, reinstall from this page.
